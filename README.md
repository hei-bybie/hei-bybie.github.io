# 河姆渡 · 一粒稻的七千年

访问网站：https://hei-bybie.github.io/

本仓库通过 GitHub Pages 发布河姆渡文化实践专栏。`index.html` 是网站首页，`assets/` 保留原网站包中的脚本、样式、264 帧滚动影像、图片、视频与论文 PDF。

## 更新网站

修改或替换对应文件后提交到 `main` 分支，GitHub Pages 将自动重新发布。`.nojekyll` 用于直接发布静态文件。

## 功能说明

支持故事插图阅读、器物卡片、滚动影像、考察记录表下载、文献搜索与分类、引文复制与导出、论文下载和视频播放。本地照片与视频选择功能仅在当前页面临时预览，刷新后不会保存到服务器，与原网站包一致。
